# Reflection

## 1. What are the strengths of using AI to create Markdown documentation?

AI helped me organize the README structure and improve the Markdown formatting. It also helped me create clear sections such as Overview, Installation, Dependencies, Example Usage, and Project Files. However, I still needed to review the content and make sure it matched my project.

## 2. What are the weaknesses or limitations of using AI?

One limitation is that AI can provide incorrect or unnecessary information. I therefore reviewed the generated content and checked the Markdown structure before using it. I also made changes where needed so the documentation matched my R project.

## 3. How did you use AI ethically in this assignment?

I used AI as a documentation and formatting assistant. I reviewed the generated suggestions instead of copying them without checking. I also included an AI Assistance Disclosure in my README and took responsibility for the final content and accuracy.
