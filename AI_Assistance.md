# AI Assistance

## AI Tool Used

ChatGPT

## Prompts Used

1. Explain what sections a good GitHub README for an R data analysis project should include.

2. Revise the sections list so it is concise and uses Markdown headers and bullet formatting.

3. Check the Markdown syntax for correctness and readability.

4. Suggest Markdown formatting and code block examples for my R script description.

5. Add sections for Installation, Example Code, and License. Keep the tone concise and professional.

6. Review the Markdown for syntax errors and suggest improvements for clarity.

## Verification and Edits

I reviewed the AI-generated suggestions and made changes to improve the structure, formatting, and clarity of the documentation. I also previewed the Markdown files on GitHub to check that the headings, code blocks, and lists displayed correctly.

## Ethical Use

AI was used as a documentation and formatting assistant. I reviewed the suggestions and made the final decisions about the content.
